# **秦朝-中央帝国的诞生**

在这里我们需要先了解一个事情，汉朝初建的时候实行的是郡国并行，也就是两条制度同时并存，一部分地区用郡县制（**朝廷直接管辖**），另一部分地区是诸侯国（**直接交给诸侯王统治的**），这种制度有很高的分裂风险，很类似小说《将进酒》里面地方强藩手握军权，中央难以制约的局面，有分崩离析的兆头。

（ 备注：《将进酒》为架空文学，仅作类比，和汉代真实郡国并行制度并不完全一致。）

秦朝为啥灭亡？根本在于战争财带来巨大的社会成本，民间经济崩塌，百姓苦不堪言，再加上刑法苛刻，最终走向王朝崩溃

庞大的集权帝国维护成本太高，说白了就是没那么多钱，因此，刘邦没有顺从“建立庞大的集权帝国”这种思潮。
